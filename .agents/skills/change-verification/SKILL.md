# change-verification

Determine impacted areas; run focused checks first, broader checks for cross-cutting risk. Report commands, exit codes, failures, and unrun checks. Never claim PASS without execution.

## Output
Provide findings or changes, evidence of checks, and unresolved limitations. Do not broaden the user’s scope.
